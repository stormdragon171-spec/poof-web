poof

Chat that cleans up after itself, with calls that ring like real calls.

Download for Android Use Poof in the browser

Install in 4 steps

  1. Tap Download for AndroidThe file is called poof.apk and is a few MB.
  2. Open the downloaded fileIf Android says it can't install from your browser, tap Settings and allow it, then go back.
  3. Tap InstallIf Play Protect warns you, tap Install anyway. Poof isn't on the Play Store yet.
  4. Open Poof and create your accountTap Allow when it asks for notifications, so your phone rings for calls.
Calls on a locked phone: if the screen doesn't light up for a call, open Android Settings, go to Apps, then Poof, then Notifications, and allow Full screen notifications.
iPhone? There is no iPhone app yet. Open Poof in Safari, tap Share, then Add to Home Screen. Calls arrive as notifications.
